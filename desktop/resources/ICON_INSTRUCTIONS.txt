Place your company logo files in this directory:

1. icon.png  — 512x512 pixels PNG (used in app header and splash)
2. icon.ico  — Windows ICO format (used for Windows installer and taskbar)

The ICO file should contain multiple sizes: 16x16, 32x32, 48x48, 256x256.

You can convert PNG to ICO using:
- Online: https://convertio.co/png-ico/
- Or use GIMP, Photoshop, etc.

The logo will appear on:
- Login screen
- App sidebar
- Print templates (receipts, job cards, delivery slips)
- Windows desktop shortcut
- Windows installer
